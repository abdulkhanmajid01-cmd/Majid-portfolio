# Abdul Majid Khan — Portfolio

Premium personal portfolio for Abdul Majid Khan, a Full-Stack Developer building web applications, SaaS platforms, AI-powered systems, automation tools and production websites.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vercel-ready

## Getting Started

```bash
npm install
npm run dev
```

## Editing Content

All project, skill, service and stat content is data-driven:

- `src/data/projects.ts` — projects, case studies, filters
- `src/data/skills.ts` — technology groups
- `src/data/services.ts` — services
- `src/data/stats.ts` — stats, engineering journey, approach, proof cards
- `src/data/site.ts` — name, GitHub, email, LinkedIn, URL

The accent color is a single CSS variable `--accent` in `src/app/globals.css`.
